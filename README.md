# Project Title

## 📌 Project Description
Smart Local Network Security & Real-Time Incident Response Dashboard is a security monitoring system designed for small local networks, home offices, and small organizations.

The system continuously monitors system resources, processes, network activity, and security-related logs using Python. The collected data is stored and managed using PostgreSQL, while the Isolation Forest machine-learning algorithm is used to identify unusual patterns and potential security incidents.

The project goes beyond simple anomaly detection by introducing an incident-response layer. When suspicious activity is detected, the system creates an incident, assigns a threat level, checks predefined security policies, and performs an authorized defensive response in a controlled environment.

A real-time dashboard provides administrators with a centralized view of system health, network activity, security alerts, active incidents, historical logs, and response status.

## 🎯 Problem Statement
Small networks often lack simple, affordable tools for real-time security monitoring and incident response. This project aims to detect abnormal system and network behaviour, identify security incidents, trigger controlled responses, and provide administrators with a real-time dashboard for monitoring and analysis.
