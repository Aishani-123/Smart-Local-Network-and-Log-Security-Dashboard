| Commit Type | Meaning                                | Example                                  |
| ----------- | -------------------------------------- | ---------------------------------------- |
| `feat`      | New feature                            | `feat: add user login`                   |
| `fix`       | Bug fix                                | `fix: fix incorrect password validation` |
| `docs`      | Documentation                          | `docs: update README`                    |
| `style`     | Formatting changes                     | `style: format code with prettier`       |
| `refactor`  | Improve code without changing behavior | `refactor: simplify login function`      |
| `perf`      | Performance improvement                | `perf: optimize database query`          |
| `test`      | Add/update tests                       | `test: add login unit tests`             |
| `build`     | Build system/dependencies              | `build: update npm dependencies`         |
| `ci`        | CI/CD changes                          | `ci: add GitHub Actions workflow`        |
| `chore`     | General maintenance                    | `chore: update project dependencies`     |
| `revert`    | Revert a previous commit               | `revert: revert login feature`           |
